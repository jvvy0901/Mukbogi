# MUKBOGI

> 먹고 싶은 음식을 "주문"하고, 걷고 뛰면서 한 입씩 "소화"해요.

MUKBOGI는 소모 칼로리를 숫자 대신 **먹고 싶은 음식**으로 보여 주는 iOS 운동 동기부여 앱입니다.
떡볶이를 주문하고 걸으면 화면 속 떡볶이가 한 입씩 줄어들고, 다 먹은 음식은 날짜별로 **냉장고**에 쌓입니다.
친구가 지금 무엇을 소화 중인지 보고, 음식을 배달해 주고, **먹보 랭킹**에서 가볍게 겨룰 수 있습니다.

이 저장소는 정식 iOS 앱을 만들기 전에 화면 흐름과 핵심 가설을 검증하는 **Streamlit 웹 프로토타입**입니다.

## 주요 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 스플래시 · 로그인 | 카카오 · 네이버 · 휴대폰 번호 / Google · Apple로 시작 |
| 회원가입 | 약관 동의 → 친구가 찾을 아이디 정하기 |
| 온보딩 | 식사량 유형(대식가 · 중식가 · 소식가) → 소화하고 싶은 음식 → 몸무게(건너뛰기 가능) |
| 홈 | 음식 주문, 식사시작 / 멈추기, 움직인 만큼 한 입씩 소화(이빨 자국 애니메이션), 조리 중인 음식, 친구 소화 현황 |
| 소화 완료 | "다 소화시켰다! 내 냉장고에 등록됐다" 연출 |
| 냉장고 | 다 먹은 음식을 날짜별로 모아 보고, 그날 소화한 총 칼로리와 목표 달성 여부 확인 |
| 커뮤니티 | 아이디로 친구 찾기 · 요청 · 수락, 먹보 랭킹(주간), 친구 냉장고 보기, 음식 배달 보내기 · 받기 |
| 내정보 | 프로필 요약, 식사량 유형 · 몸무게 · 냉장고 공개 범위 설정, MUKBOGI 플러스(광고 없이 쓰기) |

### 핵심 규칙

- **한 입** = 음식 칼로리 ÷ 입 수 (식사류 10입, 디저트 5입)
- **소모 칼로리(초안)** = 몸무게(kg, 기본 60) × 거리(km) × 활동 계수(걷기 ≈ 0.5, 달리기 ≈ 1.0)
- **하루 목표** = 등록 음식을 칼로리 순으로 3그룹으로 나눈 각 그룹 평균 (음식 10종 기준 소식가 160 · 중식가 308 · 대식가 733kcal)
- 다 소화한 뒤 남은 칼로리는 다음 조리 중 음식으로 넘어갑니다.

### 음식 (MVP 10종)

떡볶이 · 마라탕 · 파스타 · 탕후루 · 과일모찌 · 아이스크림 · 붕어빵 · 어묵탕 · 후라이드치킨 · 군고구마

## 프로토타입 범위

Streamlit 앱은 **검증용 프로토타입**이며, iOS 전용 기능은 다음처럼 흉내 냅니다.

| iOS 기능 | 프로토타입에서는 |
|---|---|
| 걷기 · 달리기 측정 | 홈의 "움직임 흉내 내기" 버튼으로 거리를 더함 |
| 소셜 로그인 · 문자 인증 | 누르면 연동된 것으로 보고 가입으로 넘어감 (인증번호는 아무 숫자 6자리) |
| 친구 · 랭킹 · 다른 유저 | 미리 만든 데모 사용자 |
| 결제 · 광고 | 실제 결제 없이 켜고 끄기, 광고는 자리만 표시 |
| 데이터 저장 | 브라우저 세션에만 저장 (새로고침하면 처음부터) |

계산 규칙(한 입, 하루 목표, 소모 칼로리, 대기열 넘김)은 정식 앱과 같게 구현되어 있습니다.

## 시작하기

### 요구 사항

- Python 3.11 이상 (개발: 3.14)
- macOS · Linux · Windows

### 설치

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
```

### 실행

```bash
.venv/bin/streamlit run app.py
```

브라우저에서 <http://localhost:8501> 이 열립니다.

### iPhone 14 크기로 보기

앱을 실행한 뒤 `preview/iphone14.html`을 브라우저로 엽니다.
iPhone 14(390 × 844pt) 프레임 안에서 상태 표시줄 · 홈 인디케이터 영역까지 흉내 내어 보여 줍니다.

```bash
open preview/iphone14.html
```

### 내 휴대폰으로 보기 (같은 Wi‑Fi)

```bash
.venv/bin/streamlit run app.py --server.address 0.0.0.0
```

휴대폰 Safari에서 `http://<맥의 내부 IP>:8501/?embed=true` 를 엽니다.
맥의 내부 IP는 `ipconfig getifaddr en0` 으로 확인할 수 있습니다.

### 테스트

```bash
.venv/bin/python -m pytest
```

계산 규칙 테스트와 `streamlit.testing.v1.AppTest`로 화면 흐름(가입 → 온보딩 → 주문 → 소화 → 냉장고 → 커뮤니티)을 확인합니다.
